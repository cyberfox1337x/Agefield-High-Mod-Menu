# Security policy

Please report a security issue privately to the repository owner through
GitHub's private vulnerability reporting feature. Do not include game saves,
tokens, passwords, crash dumps containing personal data, or copyrighted game
files in a report.

Supported security fixes target the latest published release. Compatibility
failures, unsupported game builds, and ordinary mod behavior bugs may be filed
as regular issues once issue tracking is enabled.

The installer intentionally fails closed on unverified game executables,
conflicting proxy loaders, unknown UE4SS versions, and repack or emulation
markers. Please do not request removal of those checks.
